  <h1>{{ $t('hero.title') }}</h1>

In Script:
────────────────────────────────────────────────────────────────
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n()

// Übersetzen
const title = t('hero.title')

// Sprache wechseln
locale.value = 'en'
</script>

🎯 WARUM VUE i18n BESSER IST:
═══════════════════════════════════════════════════════════════════

vs. data-* Attribute:
────────────────────────────────────────────────────────────────
❌ ALT:  <h1 data-de="Hallo" data-en="Hello">
✅ NEU:  <h1>{{ $t('greeting') }}</h1>

Vorteile:
  • Sauberer Code
  • Type-Safe
  • Zentral verwaltet
  • Einfach zu warten
  • Performance-optimiert
